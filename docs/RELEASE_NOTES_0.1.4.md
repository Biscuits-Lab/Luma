# Luma 0.1.4

## 下载与升级

- 推荐安装版：`Luma-0.1.4-windows-x64-setup.exe`。从 0.1.3 或更早的安装版升级，请关闭 Luma，运行新 Setup 并选择原安装目录。
- 免安装版：解压 `Luma-0.1.4-windows-x64.zip`，保留整个 `Luma` 文件夹，运行其中的 `Luma.exe`。
- `SHA256SUMS` 提供下载校验；依赖源代码和许可证材料单独附带。

## 图片与编辑

- 编辑器直接在主窗口图片区域打开，提供裁剪、角度校正、旋转、翻转、调整、滤镜和标记；保存后返回查看，取消时恢复查看位置和缩放。
- JPEG 完整查看支持最高 128,000,000 像素；编辑器按条带准备图片，减少大图进入编辑时的临时内存。
- 图片缩小时使用异步、有界缓存的面积过滤，改善细节闪烁和锯齿；实际像素查看、复制和另存为保留原始显示数据。
- 优化大图缩略图处理、JPEG 预缩小和工作进程内存，限制私有进程的数值库线程池。
- 图片和文件夹加载采用延迟出现的画面提示，快速加载不闪现，取消或切换图片时清理旧状态。
- 精简欢迎页，在尚未打开图片时隐藏图片操作和查看工具栏。

## 安装、更新与界面

- 安装目录第一层提供固定的 `Luma.exe` 入口，开始菜单、桌面快捷方式和打开方式在升级后指向新版本。
- 新版安装模式的应用内更新使用经过校验的 Setup，保留安装位置，并验证实际启动的进程、版本和窗口后关闭旧窗口。
- 安装界面采用自定义顶部按钮、圆角目录输入框和内嵌文件夹按钮；保留原生安装进度及高对比度回退。
- 保护现有文件和缩略图注册归属；遇到另一个 Luma 的注册时明确说明路径，由用户确认迁移。
- 改进设置页、详情面板、下拉菜单、工具提示和中文字体；设置页可查看对应版本发布说明。
- 预览启动脚本优先复用兼容的项目环境，并支持 `-CheckOnly` 检查而不打开窗口。

## 范围说明

编辑基于当前显示的 8 位 SDR 图像，默认另存为；HDR、EXR 和 RAW 编辑导出并非原始高精度数据的无损保存。原图不会被静默覆盖，删除需要确认并使用回收站。HDR 仍以 SDR 色调映射显示，直方图统计显示预览采样。深度、多部件及通道子采样 EXR 仍不支持。

旧版更新器不能被追溯修复，0.1.3 及更早安装版建议手动运行本次 Setup。便携模式采用手动下载、解压和切换目录。校验和用于检查完整性；安装包、EXE 和 DLL 尚未数字签名，Windows 可能提示未知发布者。

发布使用通过 Windows 自动化验证的同一份构建产物。自动化覆盖原生 Qt、打包解码、Shell 缩略图、200% 界面、安装生命周期和托管更新；不代表所有桌面、显示缩放、相机型号和人工 Explorer 场景均已验收。具体结果以本次 release 链接的构建记录为准。
